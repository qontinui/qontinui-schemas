        same working directory. SAME COMMAND means the whole argv is equal after normalization:
        wrappers are stripped (poetry/uv/pipenv/pdm/hatch run, npx, pnpm/npm/yarn exec, python -m,
        env, sudo, timeout N, bash/sh <script>), package-script runners are unified (npm run X = npm
        X = pnpm X = yarn X), python3 = python, pip3 = pip, and a leading ./ or trailing / is
        dropped from each word. Every other word — every flag and argument — must be equal, so
        `cargo fmt --all` does not cover `cargo fmt --all -- --check`. Verdict: COVERED (every gate
        command matched), PARTIAL (some), UNCOVERED (none), or COVERED-BY-NAME (the job has no gate
        command at all and a manifest gate job carries its imported name). A job name alone never
        covers a job that runs commands.
